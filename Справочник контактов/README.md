# Справочник контактов

## Описание проекта

Консольное приложение для управления контактами с использованием базы данных shelve. Приложение позволяет добавлять, просматривать, редактировать, удалять контакты и выводить список всех контактов.

## Структура проекта

```
Справочник контактов/
├── bd_manager.py          # Менеджер базы данных (работа с shelve)
├── contact_actions.py     # Логика действий с контактами и валидация
├── main.py               # Точка входа и главное меню
├── contacts.db           # Файл базы данных shelve
└── README.md             # Документация проекта
```

## Функциональность

### Основные возможности:
- **Добавление контакта**: Ввод имени, телефона, email и адреса с валидацией
- **Просмотр контакта**: Поиск контакта по имени
- **Редактирование контакта**: Изменение данных существующего контакта
- **Удаление контакта**: Удаление контакта по имени
- **Просмотр всех контактов**: Вывод полного списка контактов

### Валидация данных:
- **Телефон**: Проверка на корректность формата (с + или без, 7-15 цифр)
- **Email**: Базовая проверка на наличие @, домена и отсутствие запрещенных символов

## Использование

### Запуск приложения:
```bash
python main.py
```

### Меню приложения:
```
1 - Добавить контакт
2 - Просмотреть контакт
3 - Редактировать контакт
4 - Удалить контакт
5 - Показать все контакты
6 - Выход
```

## Технические детали

### Технологии:
- **Python 3.x**
- **shelve** - модуль для персистентного хранения данных в виде словаря

### Архитектура:
- **bd_manager.py**: Слой работы с базой данных
  - `open_storage()` - открытие соединения с БД
  - `get_all_contacts()` - получение всех контактов
  - `get_contact(name)` - получение контакта по имени
  - `add_contact(name, phone, email, address)` - добавление нового контакта
  - `update_contact(name, phone, email, address)` - обновление контакта
  - `delete_contact(name)` - удаление контакта

- **contact_actions.py**: Слой бизнес-логики и валидации
  - `add_contact_action()` - интерфейс добавления контакта
  - `view_contact_action()` - интерфейс просмотра контакта
  - `edit_contact_action()` - интерфейс редактирования контакта
  - `delete_contact_action()` - интерфейс удаления контакта
  - `list_all_contacts_action()` - интерфейс вывода всех контактов
  - `is_valid_phone(phone)` - валидация номера телефона
  - `is_valid_email(email)` - валидация email

- **main.py**: Слой пользовательского интерфейса
  - `display_menu()` - отображение меню
  - `main()` - главный цикл приложения

## Хранение данных

Данные хранятся в файле `contacts.db` с использованием модуля shelve. Структура данных:
- Ключ: имя контакта (строка)
- Значение: словарь с полями `phone`, `email`, `address`

## Требования

- Python 3.x
- Стандартная библиотека Python (shelve)
